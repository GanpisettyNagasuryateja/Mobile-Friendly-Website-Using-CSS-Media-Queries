# Responsive Web Design Using CSS Media Queries

## Objective
Convert an existing desktop-only webpage into a mobile-friendly webpage using CSS Media Queries. The responsive design ensures the webpage displays properly on desktops, tablets, and smartphones.

## Tools Used
- HTML
- CSS
- Visual Studio Code
- Google Chrome DevTools

## Procedure

1. Opened the existing HTML project in Visual Studio Code.
2. Identified fixed-width elements and large images that could cause layout issues on smaller screens.
3. Added CSS Media Queries targeting screens with a maximum width of **768px**.
4. Modified the layout by stacking columns vertically and reducing font sizes for better readability.
5. Updated the navigation menu to display vertically on smaller screens.
6. Tested the webpage using Chrome DevTools Device Toolbar on different screen sizes.
7. Fixed overflow and horizontal scrolling issues.
8. Made images responsive so they automatically fit within their containers.

## Outcome
The webpage was successfully converted into a responsive design. The layout, navigation menu, text, and images automatically adjust to different screen sizes, providing an improved user experience on desktops, tablets, and smartphones.
